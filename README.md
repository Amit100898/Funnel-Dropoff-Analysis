# User Funnel Drop-off Analysis

## Project Overview

This project analyzes user behavior through a conversion funnel and identifies the stage where the highest number of users abandon the process before completing a purchase.

---

##  Objective

- Analyze user journey through the funnel
- Calculate conversion rates
- Identify the biggest drop-off stage
- Visualize user conversion using Python

---

##  Dataset

- Total Records: **542**
- Columns:
  - `user_id`
  - `step`
  - `timestamp`

---

##  Technologies Used

- Python
- Pandas
- Matplotlib
- Jupyter Notebook
